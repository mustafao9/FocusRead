# 📖 FocusRead

FocusRead, haber ve makale sitelerindeki reklam, banner ve gereksiz kalabalığı temizleyerek odaklanmış bir okuma deneyimi sunan web tarayıcı eklentisidir.

## ✨ Özellikler
- 🧹 **Temiz Okuma Modu:** Reklamları, kenar çubuklarını ve önerilen haberleri ayıklar.
- 🤖 **Yapay Zeka Özeti:** Uzun makaleleri tek tıkla özetler.
- 🖍️ **Fosforlu Kalem:** Sarı, yeşil, mavi ve pembe renklerle metin işaretleme ve yerel depolama.
- 📄 **Kusursuz PDF Aktarımı:** Sayfa bölünmelerinden arındırılmış, hukuki kaynak atıflı PDF çıktısı.
- 🌍 **Dinamik Dil Desteği:** Sistem/Tarayıcı diline göre otomatik Türkçe / İngilizce arayüz.
- 🌙 **Gece Modu & Font Ayarları:** Okuma konforuna göre özelleştirilebilir görünüm.
